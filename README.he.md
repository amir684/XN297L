# XN297L

ספריית Arduino ל-**Panchip XN297L**, משדר-מקלט 2.4GHz — עם API תואם RF24, וקריאת
RSSI שהדאטהשיט לא מסביר איך להפעיל.

ה-XN297L הוא הרדיו שבתוך המון רחפני צעצוע, מכוניות RC ושלטים זולים. מפת הרגיסטרים
שלו נראית כמו של nRF24L01, ובגלל זה בדיוק דרייברים של nRF24 נכשלים עליו: ה-SPI
עובד, כל רגיסטר נקרא נכון, ושום דבר לא יוצא לאוויר. הספרייה נכתבה מול הדאטהשיט של
פאנצ'יפ ופותחה מול מודולים שפורקו מרחפן צעצוע משנת 2015.

> התיעוד המלא — ה-API, סיפור ה-RSSI, סטטוס האימות ופרויקט הדשבורד — נמצא
> ב-[README.md](README.md) באנגלית. כאן הקיצור.

## התקנה

**Arduino IDE** — מנהל הספריות, לחפש **XN297L**.

**PlatformIO**

```ini
lib_deps = amir684/XN297L
```

## התחלה מהירה

```cpp
#include <XN297L.h>

XN297L radio(4, 5);                  // CE, CSN
const uint8_t address[5] = {'N', 'o', 'd', 'e', '1'};

void setup() {
  radio.begin();
  radio.openWritingPipe(address);
  radio.stopListening();
}

void loop() {
  const char msg[] = "hello";
  radio.write(msg, sizeof(msg));
  delay(1000);
}
```

מי שמכיר את ספריית RF24 — אותם שמות ואותה התנהגות. צריך רק לשנות קבועים:
`RF24_PA_LOW` ← `XN297L_PA_LOW`.

## חיווט — שלושה דברים חשובים

- **3.3V בלבד.** טווח האספקה 2.2–3.3V, והקלט המקסימלי 3.6V. בלוחות 5V (Uno, Nano)
  צריך ממיר רמות **ומייצב 3.3V נפרד** — פין ה-3V3 של ה-Uno לא מספק את זרם השידור.
- **קבל 10µF** בין 3V3 ל-GND של המודול, צמוד לרפידות.
- טבלת פינים לכל לוח נמצאת ב-[README.md](README.md#wiring).

## ארבעת ההבדלים מ-nRF24L01

1. **`CONFIG` ביט 7 הוא `EN_PM`, וחייב להיות דלוק.** ב-nRF24 הוא שמור-אפס. בלעדיו
   ה-SPI עובד מושלם והרדיו לא משדר ולא קולט אף חבילה.
2. **`RF_SETUP` הוא 2 ביט קצב + קוד הספק של 6 ביט מטבלה קבועה** — לא סולם 0–3.
3. **ה-reset הוא פקודה עם בית נתונים**: `0x53 0x5A` מחזיק, `0x53 0xA5` משחרר.
4. **ה-SPI מוגבל ל-1Mbps** ב-power-down וב-standby-I — שם קורה כל האתחול.

## RSSI

הרגיסטר מתועד; הדרך להדליק אותו — לא. הוא נמצא בסריקת ביט-ביט של הרגיסטרים הלא
מתועדים: `RSSI_GAIN_CTR` ב-`RF_CAL` (`0x1E`, ביטים 16:15). המיקום נחזה מראש ממפת
השדות של ה-XN297, אומת בסריקה עם ספירת חבילות תקינות מול רעש, ואושר בנפרד בקוד
האתחול של פאנצ'יפ עצמה.

```cpp
radio.enableRSSI();
uint8_t strength = radio.getRSSI();   // 0-15, יחסי
radio.disableRSSI();
```

**המחיר: כ-6dB של רגישות קליטה** כל עוד הוא דלוק. לכן מדליקים לחבילות שרוצים למדוד
ומכבים — הדוגמה **RSSIMeter** דוגמת חבילה אחת מתוך ארבע.
